System architecture

FitRace Live

Cross-venue treadmill racing. Every treadmill console runs the Android runner app. One race server holds all race state in memory and pushes live rankings back to the runners and to the big screen at each venue.

Mechanisms that keep venues fair

One clock
Every device converts to server time using its min-RTT offset, so all venues see the same gun and the same finish times.
Zero at the gun
The app records the treadmill's odometer at the start time and counts only distance after it. A service restart that resets the odometer is detected and bridged.
No warm-up
Speed keys unlock only at the start. Between joining and the gun, any belt movement is commanded back to 0, so nobody gets a flying start.
Exact finish time
The finish time is interpolated between the two samples that straddle the line, instead of taking the later sample's timestamp.
Trust boundary
Telemetry is accepted only when its runnerId and roomId match the token; display tokens can never write.
Reconnect-safe
A replayed RACE_SCHEDULED with the same start time is recognised and ignored, so a dropped connection never resets distance or a finish.
Audible start
A full-screen countdown with a spoken “Five … One, Go!” plays, with a beep fallback on consoles without a speech engine.
Position alerts
From each leaderboard the app works out whether you lead, are catching the runner ahead, or are being caught. Time-gap hysteresis and cooldowns keep it from flickering; a pictogram card and a voice cue announce it.
